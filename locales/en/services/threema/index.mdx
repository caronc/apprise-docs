## Account Setup

You need to set up a [Threema Gateway](https://gateway.threema.ch/) account first. Once registered, you can request one or more 8-character **Gateway IDs** (each starting with an asterisk, e.g. `*MYGWYID`).

Apprise supports two modes:

### Basic Mode (default)

This is the simplest option. Threema handles all encryption on their servers; you do not need to manage any keys.

1. Sign up at [gateway.threema.ch](https://gateway.threema.ch/) and confirm your e-mail address.
2. Obtain credits (ask Threema support at [support-gateway@threema.ch](mailto:support-gateway@threema.ch) for a small number of test credits, or purchase them through your account).
3. [Request a Basic Gateway ID](https://gateway.threema.ch/en/id-request?type=simple). Threema will review it (usually within one or two business days) and create the ID. The corresponding **API secret** appears on the ID overview page.

You can now send to any recipient by their Threema ID, phone number, or e-mail address.

### End-to-End Encrypted Mode (`?mode=e2e`)

In E2E mode your messages are encrypted on your own machine before being sent; Threema's servers never see the plaintext.

**Before you begin:** you must generate a Curve25519 key pair yourself. The E2E registration form requires your **public key** — Threema does not generate one for you. You keep the **private key** and never share it; it is what goes into your Apprise URL later.

**Step 1 — Generate a Key Pair**

<Tabs>
<TabItem label="Python">

Works on Linux, macOS, and Windows. Install PyNaCl (also required by Apprise at runtime for E2E mode):

```bash
pip install pynacl
```

Generate your key pair:

```python
from nacl.public import PrivateKey
key = PrivateKey.generate()
print("private:", key.encode().hex())
print("public: ", key.public_key.encode().hex())
```

</TabItem>
<TabItem label="PowerShell">

Windows PowerShell 5.1 does not support X25519. [PowerShell 7+](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows) (which ships with .NET 6 or later) is required:

```powershell
$ecdh    = [System.Security.Cryptography.ECDiffieHellman]::Create("X25519")
$privDer = $ecdh.ExportPkcs8PrivateKey()
$pubDer  = $ecdh.ExportSubjectPublicKeyInfo()
"private: $(($privDer | Select-Object -Last 32 | ForEach-Object { '{0:x2}' -f $_ }) -join '')"
"public:  $(($pubDer  | Select-Object -Last 32 | ForEach-Object { '{0:x2}' -f $_ }) -join '')"
```

Note: Apprise still requires PyNaCl installed at runtime to send E2E messages (`pip install pynacl`).

</TabItem>
</Tabs>

Either method produces two 64-character hex strings. The `private:` value is your Apprise private key — keep it secret. Copy the `public:` value; you will paste it into the registration form in Step 2.

**Step 2 — Register an E2E Gateway ID**

Open the [E2E ID request form](https://gateway.threema.ch/en/id-request?type=e2e) and complete it:

- **Public Key** — paste the 64-character hex value from the `public:` line generated in Step 1.
- **URL for incoming messages** — optional; used only for delivery-report callbacks. Leave it blank if you do not need incoming message handling.
- A **1,600-credit setup fee** is charged when the ID is approved.

After Threema reviews your request (usually within one or two business days), the ID is created and the **API Secret** appears on the ID overview page.

Your private key (the 64-character hex string from Step 1) is the `privkey` value in your Apprise URL. Apprise accepts it in either format:

```text
private:aabbccddeeff00112233445566778899aabbccddeeff00112233445566778899
```

or just the raw 64-character hex part without the `private:` prefix — both are equivalent. Keep it secret — anyone with it can send messages as your Gateway ID.

**Note:** E2E mode only supports **Threema ID** targets (8-character IDs like `ABCD1234`). Phone numbers and e-mail addresses are not supported in this mode.

## Syntax

Valid syntax is as follows:

- `threema://{gateway_id}@{secret}/{user}`
- `threema://{gateway_id}@{secret}/{user1}/{user2}/{user3}/{userN}`
- `threema://{gateway_id}@{secret}/{email}`
- `threema://{gateway_id}@{secret}/{email1}/{email2}/{email3}/{emailN}`
- `threema://{gateway_id}@{secret}/{phone}`
- `threema://{gateway_id}@{secret}/{phone1}/{phone2}/{phone3}/{phoneN}`

You can also freely mix target types:

- `threema://{gateway_id}@{secret}/{phone1}/{user1}/{email1}/...`

For end-to-end encrypted mode (Threema IDs only):

- `threema://{gateway_id}@{secret}/{user}?mode=e2e&privkey={privkey}`
- `threema://{gateway_id}@{secret}/{user1}/{user2}?mode=e2e&privkey={privkey}`

The `{privkey}` value is your 64-character hex private key. You can paste it in either of these two equivalent forms:

- Raw hex (just the 64 characters): `?privkey=aabbcc...`
- Full SDK format (with the `private:` prefix): `?privkey=private:aabbcc...`

Both forms are accepted.

## Parameter Breakdown

| Variable   | Required | Description                                                                                                                                                        |
| ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| gateway_id | Yes      | Your Gateway ID, e.g. `*MYGWYID`. The leading `*` is optional — Apprise prepends it automatically if omitted. Aliases: `?from=` or `?gwid=`.                       |
| secret     | Yes      | The API secret shown on your Gateway ID overview page. Alias: `?secret=`.                                                                                          |
| target     | No       | Who to notify: a Threema ID (8 chars), phone number, or e-mail address. No limit on the number of targets. Alias: `?to=`. E2E mode accepts Threema IDs only.       |
| mode       | No       | Set to `e2e` to enable end-to-end encrypted messaging (requires PyNaCl and an E2E Gateway ID). Defaults to `basic`.                                                |
| privkey    | No       | Your Curve25519 private key as a 64-character hex string. Required when `mode=e2e`. Accepts raw hex (`aabbcc...`) or the Threema SDK format (`private:aabbcc...`). |

## Examples

Send a Basic notification to a recipient by their Threema ID:

```bash
# Assume:
#  - your {gateway_id} is *MYGWYID
#  - your {secret} is abc123-2345
#  - the recipient {toThreemaID} is FRIENDID
apprise -vv -t "Test Message Title" -b "Test Message Body" \
   threema://*MYGWYID@abc123-2345/FRIENDID
```

Send a Basic notification by phone number:

```bash
# Assume:
#  - your {gateway_id} is *MYGWYID
#  - your {secret} is abc123-2345
#  - the recipient phone number is +1 613 555 1234
apprise -vv -t "Test Message Title" -b "Test Message Body" \
   threema://*MYGWYID@abc123-2345/16135551234
```

Send an end-to-end encrypted notification (E2E mode):

```bash
# Assume:
#  - your {gateway_id} is *MYGWYID  (must be an E2E Gateway ID)
#  - your {secret} is abc123-2345
#  - your private key (generated in Step 1) is:
#      private:aabbccddeeff001122...  (64 hex chars after "private:")
#  - the recipient {toThreemaID} is FRIENDID
#
# Option 1: paste the key exactly as shown by the key-generation tool
apprise -vv -t "Test Message Title" -b "Test Message Body" \
   "threema://*MYGWYID@abc123-2345/FRIENDID?mode=e2e&privkey=private:aabbccddeeff001122334455667788990011223344556677889900112233445566"

# Option 2: paste just the 64-character hex part (without "private:")
apprise -vv -t "Test Message Title" -b "Test Message Body" \
   "threema://*MYGWYID@abc123-2345/FRIENDID?mode=e2e&privkey=aabbccddeeff001122334455667788990011223344556677889900112233445566"
```
