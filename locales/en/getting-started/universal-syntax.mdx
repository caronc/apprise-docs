Every destination in Apprise is written as one URL. Learn its four parts once and you can read or write a URL for any of the <!-- SERVICES:COUNT --> [supported services](/services/).

:::tip[No Need to Memorize This]
The [URL Builder](/url-builder/) asks for each value in a simple form and writes the URL for you. Every [service page](/services/) also lists the exact URL formats that service accepts.
:::

## The Blueprint

The service is always there. Which of the other three parts you need depends on the service.

## Breakdown

### 1. The Service (`service://`)

The first part picks the service Apprise talks to. Many services have a secure form ending in `s`, such as `mailtos://` or `ntfys://`, which uses an encrypted connection.

<div class="url-anatomy url-anatomy--compact" data-focus="schema">
  <ul class="url-anatomy__examples url-anatomy__examples--noted">
    <li>
      <span class="ua-note">Email</span>
      <span class="ua-schema">mailtos://</span>
      <span class="ua-creds">user:pass@gmail.com</span>
      <span class="ua-target">/jane@example.com</span>
      <span class="ua-params"></span>
    </li>
    <li>
      <span class="ua-note">Telegram</span>
      <span class="ua-schema">tgram://</span>
      <span class="ua-creds">bottoken</span>
      <span class="ua-target">/chat_id</span>
      <span class="ua-params"></span>
    </li>
    <li>
      <span class="ua-note">Slack</span>
      <span class="ua-schema">slack://</span>
      <span class="ua-creds">TokenA/TokenB/TokenC</span>
      <span class="ua-target">/#general</span>
      <span class="ua-params"></span>
    </li>
  </ul>
</div>

Not sure what yours is called? [Browse every supported service](/services/).

### 2. Credentials and Host

This part tells the service who you are, or where your server lives. Depending on the service it is a token, a user name and password, or the address of a server you run yourself.

<div class="url-anatomy url-anatomy--compact" data-focus="creds">
  <ul class="url-anatomy__examples url-anatomy__examples--noted">
    <li>
      <span class="ua-note">A bot token</span>
      <span class="ua-schema">tgram://</span>
      <span class="ua-creds">bottoken</span>
      <span class="ua-target">/chat_id</span>
      <span class="ua-params"></span>
    </li>
    <li>
      <span class="ua-note">A login and mail server</span>
      <span class="ua-schema">mailtos://</span>
      <span class="ua-creds">user:pass@example.com</span>
      <span class="ua-target">/jane@example.com</span>
      <span class="ua-params"></span>
    </li>
    <li>
      <span class="ua-note">A self-hosted server</span>
      <span class="ua-schema">ntfys://</span>
      <span class="ua-creds">ntfy.example.com</span>
      <span class="ua-target">/my-topic</span>
      <span class="ua-params"></span>
    </li>
  </ul>
</div>

:::caution[Special Characters]
If a password or token contains characters such as `@`, `/`, `:` or `#`, encode them or Apprise will split the URL in the wrong place. For example, `@` becomes `%40`. See [URL Construction](/qa/special-characters/) for the full list.
:::

### 3. The Direction (`/direction`)

This part says where the message goes: a channel, a chat, a topic, a phone number, or a person. Many services take several at once, separated by `/`.

<div class="url-anatomy url-anatomy--compact" data-focus="target">
  <ul class="url-anatomy__examples url-anatomy__examples--noted">
    <li>
      <span class="ua-note">Two channels</span>
      <span class="ua-schema">slack://</span>
      <span class="ua-creds">TokenA/TokenB/TokenC</span>
      <span class="ua-target">/#general/#alerts</span>
      <span class="ua-params"></span>
    </li>
    <li>
      <span class="ua-note">A phone number</span>
      <span class="ua-schema">twilio://</span>
      <span class="ua-creds">AccountSid:AuthToken@15551234567</span>
      <span class="ua-target">/15557654321</span>
      <span class="ua-params"></span>
    </li>
    <li>
      <span class="ua-note">A chat</span>
      <span class="ua-schema">tgram://</span>
      <span class="ua-creds">bottoken</span>
      <span class="ua-target">/chat_id</span>
      <span class="ua-params"></span>
    </li>
  </ul>
</div>

### 4. Parameters (`?key=value`)

Optional settings go at the end, after a `?`. Each one is written as `key=value`, and several are joined with `&`. Most belong to one service, but a few such as `format=` work everywhere (see [Formatting](/getting-started/formatting/)).

<div class="url-anatomy url-anatomy--compact" data-focus="params">
  <ul class="url-anatomy__examples url-anatomy__examples--noted">
    <li>
      <span class="ua-note">Read the message aloud</span>
      <span class="ua-schema">discord://</span>
      <span class="ua-creds">webhook_id/webhook_token</span>
      <span class="ua-target"></span>
      <span class="ua-params">?tts=yes</span>
    </li>
    <li>
      <span class="ua-note">Send the email as HTML</span>
      <span class="ua-schema">mailtos://</span>
      <span class="ua-creds">user:pass@gmail.com</span>
      <span class="ua-target">/jane@example.com</span>
      <span class="ua-params">?format=html</span>
    </li>
    <li>
      <span class="ua-note">Raise the priority</span>
      <span class="ua-schema">ntfys://</span>
      <span class="ua-creds">ntfy.example.com</span>
      <span class="ua-target">/my-topic</span>
      <span class="ua-params">?priority=high</span>
    </li>
  </ul>
</div>

Each [service page](/services/) lists the parameters it supports.

## Where URLs Are Used

The same URL works everywhere in Apprise, so one you test on the command line can go straight into a config file or an API call.

<Tabs>
<TabItem label="Command Line">

```bash
apprise -b "Hello" "tgram://bottoken/chat_id"
```

</TabItem>
<TabItem label="YAML Config">

```yaml
urls:
  - tgram://bottoken/chat_id
```

</TabItem>
<TabItem label="Text Config">

```text
tgram://bottoken/chat_id
```

</TabItem>
<TabItem label="API Call">

```bash
curl -X POST -H "Content-Type: application/json" \
    -d '{"urls": "tgram://bottoken/chat_id", "body": "Hello"}' \
    http://localhost:8000/notify/
```

</TabItem>
</Tabs>
