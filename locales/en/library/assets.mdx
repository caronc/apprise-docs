`AppriseAsset` defines the **global execution context** for an Apprise session.

It is not limited to branding or theming. An asset instance influences behaviour across:

- All notification plugins
- All delivery threads
- Persistent storage and key material
- Global safety boundaries (log redaction and recursion protection)

Under usual conditions, an asset is created once and then passed into `Apprise(...)` during its instantiation.

```python
from apprise import Apprise, AppriseAsset

asset = AppriseAsset(app_id="My Application", theme="default")
apobj = Apprise(asset=asset)
```

If no asset is provided, Apprise creates a default one.

## Lifecycle and Scope

- Created once, typically at application startup
- Shared across all loaded plugins and configuration processing
- Intended to be treated as immutable for the lifetime of an `Apprise` instance

Mutating an asset after it has been bound to `Apprise` can produce inconsistent results across plugins.

## Object Initialization

`AppriseAsset.__init__()` provides named arguments for storage, timeouts,
payload limits, and other shared settings. Always use the documented
constructor name, such as `timezone=`, `service_timeout=`, or
`payload_max_size=`. These arguments validate values before applying them.

Python constructor arguments and YAML `asset:` keys are separate interfaces.
Some settings are available to applications through `AppriseAsset(...)` but
are intentionally unavailable to YAML configuration.

## Defaults and Field Reference

This table documents the **actual defaults** from the implementation, plus where each field is used.

### Identity and Presentation

| Field                | Type              |                             Default | Used by                              | Notes                                                                                      |
| -------------------- | ----------------- | ----------------------------------: | ------------------------------------ | ------------------------------------------------------------------------------------------ |
| `app_id`             | `str`             |                           `Apprise` | Plugin headers, key generation names | Used as a human-facing application identifier and as a default name in PGP key generation. |
| `app_desc`           | `str`             |             `Apprise Notifications` | Metadata / Presentation              | Used by tooling and services that display an application description.                      |
| `app_url`            | `str`             | `https://github.com/caronc/apprise` | Metadata / Presentation              | Provider URL exposed in docs and some plugin metadata.                                     |
| `theme`              | `str`             |                           `default` | Icon URL/path resolution             | Drives `{THEME}` substitution for icon lookup.                                             |
| `default_extension`  | `str`             |                              `.png` | Icon URL/path resolution             | Used when `extension` is not provided to `image_url()` or `image_path()`.                  |
| `default_image_size` | `NotifyImageSize` |                            `XY_256` | Icon URL resolution                  | Used when size is omitted.                                                                 |
| `image_url_mask`     | `str`             |                      GitHub raw URL | `image_url()`                        | Produces a themed image URL for `NotifyType` + size.                                       |
| `image_url_logo`     | `str`             |                      GitHub raw URL | `image_url(logo=True)`               | Used for the application logo.                                                             |
| `image_path_mask`    | `str`             |           local `assets/themes/...` | `image_path()` / `image_raw()`       | Used for local icon resolution and raw bytes loading.                                      |

### Type Mapping Helpers

| Field                 | Type                   |        Default | Used by   | Notes                                             |
| --------------------- | ---------------------- | -------------: | --------- | ------------------------------------------------- |
| `html_notify_map`     | `dict[NotifyType,str]` |   type→hex map | `color()` | Default colour mapping for HTML-capable services. |
| `default_html_color`  | `str`                  |      `#888888` | `color()` | Used when a mapping is missing.                   |
| `ascii_notify_map`    | `dict[NotifyType,str]` | type→token map | `ascii()` | Default ASCII tokens for text-only contexts.      |
| `default_ascii_chars` | `str`                  |          `[?]` | `ascii()` | Used when a mapping is missing.                   |

### Content Interpretation

| Field               | Type           | Default | Used by                | Notes                                                                                                                                             |
| ------------------- | -------------- | ------: | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `body_format`       | `NotifyFormat` |  `None` | Message pre-processing | Selects the default input format. If `None`, no pre-formatting is applied.                                                                        |
| `interpret_emojis`  | `bool`         |  `None` | Message pre-processing | Controls emoji conversion. If `None`, it defers to each service (for example, `emojis=yes` at the URL level).                                     |
| `interpret_escapes` | `bool`         | `False` | Message pre-processing | Enables `\n`, `\t`, etc. prior to sending.                                                                                                        |
| `encoding`          | `str`          | `utf-8` | Encoding               | Used when encoding strings for processing and by some services when sending content. Keep the default unless a service requires another encoding. |

### Concurrency and Delivery

| Field                    | Type            | Default | Used by                | Notes                                                                                                                                                                                                  |
| ------------------------ | --------------- | ------: | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `async_mode`             | `bool`          |  `True` | Delivery orchestration | Controls concurrent vs sequential dispatch.                                                                                                                                                            |
| `default_service_retry`  | `int`           |     `0` | Per-service retry      | Fallback retry count for any service that does not set `?retry=` in its URL. Clamped to `[0, 10]`.                                                                                                     |
| `default_service_wait`   | `float`         |   `0.5` | Per-service retry      | Fallback inter-retry pause (seconds) for services without `?wait=`. Clamped to `[0.0, 20.0]`.                                                                                                          |
| `service_timeout`        | `int` / `float` |  `60.0` | Per-service timeout    | Maximum seconds a single service (including all of its retries) may take before Apprise gives up on it and reports a `TIMEOUT`. `0` disables the limit. See [Notification Results](/library/results/). |
| `result_log_memory_size` | `int`           |     `0` | Result logs            | Bytes kept in memory before result logs spill to temporary disk storage. Used only when `result_log_disk_size` is greater than `0`.                                                                    |
| `result_log_disk_size`   | `int`           |     `0` | Result logs            | Maximum temporary disk space for one notification result. `0` keeps all result logs in memory.                                                                                                         |

### Plugin Discovery

| Field          | Type        | Default | Used by               | Notes                                                   |
| -------------- | ----------- | ------: | --------------------- | ------------------------------------------------------- |
| `plugin_paths` | `list[str]` |    `[]` | Custom plugin loading | Triggers module detection at asset initialisation time. |

### Persistent Storage

| Field           | Type                  | Default | Used by                   | Notes                                                                                           |
| --------------- | --------------------- | ------: | ------------------------- | ----------------------------------------------------------------------------------------------- |
| `storage_path`  | `str`                 |  `None` | PersistentStore           | PersistentStore root. If unset, Apprise operates memory-only for storage-backed features.       |
| `storage_mode`  | `PersistentStoreMode` |  `auto` | PersistentStore behaviour | `auto`, `flush`, `memory`.                                                                      |
| `storage_idlen` | `int`                 |     `8` | Namespace generation      | Controls how long generated namespace directories are.                                          |
| `storage_salt`  | `bytes`               |   `b""` | Namespace generation      | Provides optional salting for namespace generation, string values are encoded using `encoding`. |

### Key Material Management

| Field         | Type   | Default | Used by        | Notes                                                                                                                                                                                                                                                                    |
| ------------- | ------ | ------: | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `pgp_autogen` | `bool` |  `True` | PGP controller | When `True` and persistent storage is configured, generates an RSA-2048 key pair (`{localpart}-pub.asc` + `{localpart}-prv.asc`) the first time no key is found. Only applies to `pgp=encrypt` mode — the opportunistic-encrypt step of `pgp=sign` never auto-generates. |
| `pem_autogen` | `bool` |  `True` | PEM controller | Enables auto-generation of PEM keys when storage allows it and no key is provided.                                                                                                                                                                                       |

#### PGP Auto-Generation Details

When `pgp_autogen = True`, Apprise generates **both** a public and a private key on the first `pgp=encrypt` send where no key is found:

- `{localpart}-pub.asc` — RSA-2048 public key, used to encrypt outbound messages
- `{localpart}-prv.asc` — RSA-2048 private key, auto-discovered by `pgp=sign` mode

`{localpart}` is derived from the sender's From address (everything before `@`, lowercased).

This means bootstrapping is automatic: configure `pgp=encrypt` once with persistent storage, let the first send generate both keys, then switch to `pgp=sign` and the private key will be discovered from the same storage directory without any `pgpprv=` parameter.

To disable auto-generation globally:

```python
from apprise import AppriseAsset

asset = AppriseAsset(
    storage_path="/var/lib/apprise",
    pgp_autogen=False,
)
```

With `pgp_autogen = False`, no key pair is created automatically. Apprise falls back to the next discovery method (WKD or an explicit `pgppub=` path) and fails the send if no key is found.

### Safety Boundaries

| Field                      | Type             |   Default | Used by                      | Notes                                                                                                                                                                                                       |
| -------------------------- | ---------------- | --------: | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `http_redirects`           | `bool`           |    `True` | All HTTP plugins             | When `True` (the default), plugins follow 3xx redirects, matching the behaviour of the underlying requests library. Set to `False` to disable redirect following globally without touching individual URLs. |
| `secure_logging`           | `bool`           |    `True` | Logging pipeline             | Adds overhead to redact secrets from logs, recommended to keep enabled.                                                                                                                                     |
| `payload_max_size`         | `int`            |       `0` | Message formatting/splitting | Optional input ceiling for the combined title and body. `0` disables it. Applies to every `overflow=` mode.                                                                                                 |
| `payload_buffer_threshold` | `int`            |      `10` | Message formatting/splitting | A title or body at or below this length may remain whole; see [Payload Size Cap](#payload-size-cap).                                                                                                        |
| `payload_min_buffer`       | `int`            |      `25` | Message formatting/splitting | Characters reserved for the other side before keeping a short side whole; see [Payload Size Cap](#payload-size-cap).                                                                                        |
| `timezone`                 | `str` / `tzinfo` | system tz | Time-based behaviour         | Sets the timezone used by plugins that generate timestamps. Accepts an IANA name such as `"America/Toronto"` or a `tzinfo` object. YAML accepts `timezone` or its `tz` alias.                               |

## Common Usage Patterns

<Tabs>

<TabItem value="identity" label="Identity & Branding">

Configures the Apprise instance to use an altered branding.

```python
from apprise import AppriseAsset

asset = AppriseAsset(
    app_id="StatsBot",
    app_desc="Metrics Aggregation Service",
    app_url="https://example.com",
)
```

</TabItem>

<TabItem value="concurrency" label="Concurrency">

Disables concurrent delivery and forces sequential notification dispatch.

```python
from apprise import AppriseAsset

# Force sequential sending (no concurrency)
asset = AppriseAsset(async_mode=False)
```

</TabItem>

<TabItem value="timeout" label="Service Timeout">

Give every service in the session the same time budget, instead of the default
60 seconds. See [Notification Results](/library/results/) for how a service
that runs out of time is reported back to you.

```python
from apprise import Apprise, AppriseAsset

# Give each service 10 seconds (including all of its own retries)
# before Apprise gives up on it and reports a TIMEOUT
asset = AppriseAsset(service_timeout=10)

apobj = Apprise(asset=asset)
apobj.add("slack://tokenA/tokenB/tokenC")

# This one call also gets its own 30-second ceiling, on top of the
# asset's own 10-second-per-service budget -- whichever is sooner wins
apobj.notify(body="Time-sensitive alert", timeout=30)
```

</TabItem>

<TabItem value="result-logs" label="Result Log Storage">

Keep a small result-log buffer in memory and place later entries in an
automatically removed temporary file:

```python
from apprise import Apprise, AppriseAsset

asset = AppriseAsset(
    result_log_memory_size=2 * 1024 * 1024,
    result_log_disk_size=256 * 1024 * 1024,
)
apobj = Apprise(asset=asset)
```

The limits are shared by all services and retries in one notification. If the
disk allowance is exhausted or unavailable, delivery continues and the result
contains a warning that later log entries could not be retained.

</TabItem>

<TabItem value="plugins" label="Custom Plugins">

When `plugin_paths` is set, module detection occurs during asset initialization.

```python
from apprise import AppriseAsset

asset = AppriseAsset(
    plugin_paths=[
        "/opt/apprise/plugins",
        "/srv/myapp/apprise_plugins",
    ]
)
```

</TabItem>

<TabItem value="storage" label="Persistent Storage">

Controls disk-backed caching and plugin state.

```python
from apprise import AppriseAsset
from apprise.common import PersistentStoreMode

asset = AppriseAsset(
    storage_path="/var/lib/apprise",
    storage_mode=PersistentStoreMode.AUTO,
    storage_idlen=12,
    storage_salt="my-namespace-salt",
)
```

`storage_salt` may be `bytes` or `str`. String values are encoded using the asset `encoding`.

</TabItem>

<TabItem value="timezone" label="Timezone Control" >

Plugins that generate timestamps (for example email Date headers) use the
configured timezone.

```python
from apprise import AppriseAsset

asset = AppriseAsset(timezone="America/Toronto")
```

  </TabItem>

</Tabs>

## Icon and Image Resolution

Apprise resolves icons using configurable masks.

```python
asset = AppriseAsset(
    image_path_mask="/icons/{THEME}/{TYPE}-{XY}{EXTENSION}",
    image_url_mask="https://cdn.example.com/{TYPE}-{XY}{EXTENSION}",
)
```

| Token         | Description                     |
| ------------- | ------------------------------- |
| `{THEME}`     | Active theme                    |
| `{TYPE}`      | info, success, warning, failure |
| `{XY}`        | Image size                      |
| `{EXTENSION}` | File extension                  |

## Security and Safety Controls

### HTTP Redirects

By default, Apprise follows HTTP 3xx redirects, matching the behaviour of the
underlying requests library. If you want to prevent custom headers and
credentials from being forwarded to destinations that differ from the original
URL, you can disable redirect following globally:

```python
asset = AppriseAsset(http_redirects=False)
```

Individual URLs can still override the asset default using the `redirect=`
URL parameter:

```text
# Override per-URL regardless of the asset setting
schema://token/?redirect=yes
schema://token/?redirect=no
```

### Secure Logging

When enabled, secrets are redacted from all logging output.

```python
asset = AppriseAsset(secure_logging=True)
```

Disabling this is strongly discouraged outside isolated environments.

### Payload Size Cap

`payload_max_size` is the payload limit, or total character budget (`N`), for
the title and body before formatting or splitting begins. A value of `0`
disables the limit. If the title and body already fit within `N`, Apprise
leaves both unchanged.

```python
asset = AppriseAsset(payload_max_size=100000)
```

Three settings work together when the content is larger than `N`:

| Setting                    | Default | Purpose                                                                   |
| -------------------------- | ------- | ------------------------------------------------------------------------- |
| `payload_max_size`         | `0`     | Sets `N`, the total budget. `0` disables the limit.                       |
| `payload_buffer_threshold` | `10`    | A title or body of this length or shorter may be kept whole.              |
| `payload_min_buffer`       | `25`    | Space the other side must retain before the short side can be kept whole. |

With the default values, an oversized payload is resolved in this order:

1. **One side is empty:** The other side receives the full budget.
2. **One side is short:** A title of 10 characters or fewer stays whole if
   the body can keep 25 characters, or its full length when shorter. The
   same rule then checks for a short body. If both qualify, the title is
   checked first.
3. **Otherwise:** The title and body share `N` in proportion to their
   original lengths. When `N` has room for both, each keeps at least one
   character.

For example, a 20-character title and an 18-character body with `N=20`
split approximately 10/10. A smaller cap may still leave a short fragment,
but it does not favor one side when both can be represented.

Library users can change both settings when constructing the asset:

```python
asset = AppriseAsset(
    payload_max_size=100000,
    payload_buffer_threshold=10,
    payload_min_buffer=25,
)
```

Setting `payload_min_buffer=0` removes the reservation, so a qualifying
short side may use the entire cap.

Formatting and escaping can add a few characters afterward. The limit
applies to every `overflow=` mode, including `upstream`.

## Configuration File Boundaries

YAML deliberately supports a smaller set of asset settings than the Python
constructor. Numeric controls such as `service_timeout`, `payload_max_size`,
`payload_buffer_threshold`, and `payload_min_buffer` must be supplied
through their named `AppriseAsset(...)` arguments. Plugin paths and storage
settings are also application-controlled so configuration files cannot load
code or redirect persistent storage.

`timezone` is supported in YAML and may also use the `tz` alias:

```yaml
asset:
  timezone: America/Toronto # or: tz: America/Toronto
```
