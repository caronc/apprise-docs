Le nom **Apprise** (/əˈpraɪz/) se prononce comme « uh-prise », proche de _surprise_ ou _arise_, avec l'accent sur la deuxième syllabe.

**Apprise** est une bibliothèque d'acheminement de notifications qui normalise la manière dont les messages sont remis à plus de 100 services différents. Elle retire la complexité de l'envoi de notifications.

Elle ne remplace pas les plateformes de discussion, les fournisseurs de messagerie ou les systèmes d'alerte. Elle fournit plutôt une manière unique et cohérente de leur envoyer des notifications.

Que vous soyez administrateur système en train d'automatiser des scripts, développeur en train de construire une application ou ingénieur DevOps gérant des services distribués, Apprise supprime le besoin d'apprendre et de maintenir des dizaines d'API propres à chaque fournisseur.

## Une syntaxe unique pour tout piloter

Au cœur d'Apprise se trouve l'**URL universelle de notification**.

Au lieu d'apprendre un format de charge utile propre à chaque service, vous configurez vos destinations à l'aide d'une syntaxe unique et prévisible :

```text
service://credentials/direction/?parameter=value
```

Si vous décidez plus tard de passer d'un service à un autre, la logique de votre application ne change pas. Il vous suffit de mettre à jour la configuration de l'URL.

Cette approche rend les notifications portables, faciles à maintenir et simples à comprendre.

## Les trois piliers d'Apprise

Apprise est unique parce qu'il ne s'agit pas seulement d'une bibliothèque : c'est une plateforme disponible sous trois formes complémentaires.

### 1. La bibliothèque Python

_Pour les développeurs_

Au cœur du projet, Apprise est une bibliothèque Python légère. Vous l'intégrez directement dans votre application et vous envoyez des notifications en seulement quelques lignes de code.

```python
import apprise

apobj = apprise.Apprise()

# Add a service
apobj.add("tgram://credentials")

# Notification destinations are configured separately
apobj.notify(
    body="Hello World",
    title="My Notification",
)
```

Le même code fonctionne quel que soit le service de notification configuré.

### 2. L'interface en ligne de commande (CLI)

_Pour les administrateurs système et l'automatisation_

Apprise est livré avec une puissante CLI qui expose les mêmes fonctionnalités sans nécessiter de code Python. C'est idéal pour les tâches cron, les scripts de sauvegarde, les hooks de supervision et les pipelines CI/CD.

```bash
# e.g: Send a notification to Discord
apprise -t "Backup Complete" -b "The server is safe" \
  "discord://webhook_id/webhook_token"
```

### 3. Le serveur API

_Pour les environnements centralisés et distribués_

Apprise est aussi disponible sous la forme d'un serveur API conteneurisé et sans état. Cela vous permet d'exploiter une « passerelle de notifications » centralisée pour plusieurs systèmes.

Vous pouvez :

- Envoyer des notifications directement à chaque requête (sans état)
- Stocker les configurations côté serveur et les référencer par clé (avec état)

Cette approche est particulièrement utile pour les microservices, les infrastructures partagées et les équipes qui veulent centraliser le contrôle.

## Fonctionnalités clés

- **{/_ SERVICES:COUNT _/} services pris en charge**, des plateformes de discussion populaires aux passerelles spécialisées
- **Diffusion adaptée au format**, avec prise en charge du Markdown, du HTML et du texte brut
- **Prise en charge des pièces jointes**, adaptée automatiquement aux capacités de chaque service
- **Hautes performances**, avec livraison parallèle des notifications
- **Dépendances minimales**, pour rester léger
