Cette page présente les parties de l'application que vous utiliserez tous les jours. Chaque image porte des repères numérotés, expliqués à côté. Les images suivent le choix clair ou sombre en haut de ce site : vous voyez l'application avec le même thème que celui de votre lecture.

Si l'application n'est pas encore reliée à votre serveur, commencez par [Configurer Apprise Mobile](/mobile/getting-started/).

## Le Tableau de Bord

Le tableau de bord liste chaque service auquel votre serveur peut envoyer, regroupés sous chaque Config ID. La barre de couleur à gauche distingue les Config ID, et la ligne sous l'adresse indique si le serveur a répondu à sa dernière vérification.

## Désactiver et Réactiver un Config ID

Faites glisser l'en-tête d'un Config ID vers la gauche puis relâchez pour le désactiver. Il devient gris, et ses services sont laissés de côté lors des envois, des vérifications et des actualisations. Glissez de nouveau vers la gauche pour le réactiver.

Faites glisser l'en-tête d'un Config ID vers la droite pour faire apparaître ses raccourcis. Ils restent ouverts jusqu'à ce que vous rameniez l'en-tête.

- **Réglages** (l'engrenage) : modifier l'adresse, l'identifiant ou la couleur du serveur.
- **Actualiser** : vérifier le serveur et télécharger de nouveau sa liste de services.
- Certains serveurs proposent aussi de déplacer la configuration vers un nouveau Config ID, ou d'en changer le mot de passe.

## Modèles

Un modèle est un message enregistré, avec son titre, son corps et ses destinataires, prêt à être renvoyé d'un simple glissement. Les modèles nécessitent la version complète de l'application.

<figure class="mobile-guide-shot mobile-guide-shot--crop">
  <img
    class="mobile-guide-light"
    src="/assets/mobile-guide/templates-fr-light.webp"
    alt="L'écran Modèles. 1 : glissez à droite pour envoyer un modèle. 2 : le supprimer. 3 : maintenez et glissez pour réordonner."
    width="860"
    height="1080"
    loading="lazy"
  />
  <img
    class="mobile-guide-dark"
    src="/assets/mobile-guide/templates-fr-dark.webp"
    alt="L'écran Modèles. 1 : glissez à droite pour envoyer un modèle. 2 : le supprimer. 3 : maintenez et glissez pour réordonner."
    width="860"
    height="1080"
    loading="lazy"
  />
</figure>

- Touchez **Créer** sur l'écran Modèles pour en écrire un nouveau, ou transformez un message déjà envoyé en modèle depuis son rapport de livraison.
- Faites glisser un modèle vers la droite pour l'envoyer.
- Touchez un modèle pour le voir ou le modifier, maintenez la poignée à droite pour le déplacer, ou touchez la corbeille pour le supprimer.

Les bons candidats sont les messages que vous envoyez souvent : « Le repas est servi », « En route vers la maison » ou « En retard ».

## Clair et Sombre

L'application suit le réglage clair ou sombre de votre téléphone. Pour en choisir un vous-même, ouvrez **Paramètres > Apparence**. Le même menu propose **Langue**, pour choisir une langue d'application différente de celle de votre téléphone.
