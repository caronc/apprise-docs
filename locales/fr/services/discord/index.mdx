## Configuration du Compte

Créer un compte Discord est simple. La seule étape demandant un peu plus de travail intervient une fois votre salon configuré (par défaut, Discord vous place dans un salon `#General`). Cliquez sur l'icône en forme d'engrenage (Settings), puis activez les webhooks à partir de là.

Le webhook ressemblera à quelque chose comme ceci :
`https://discordapp.com/api/webhooks/4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js`

Cela correspond en pratique à :
`https://discordapp.com/api/webhooks/{WebhookID}/{WebhookToken}`

La dernière partie de l'URL fournie constitue les 2 jetons dont vous avez besoin pour envoyer des notifications. Dans l'exemple ci-dessus, les jetons sont les suivants :

1. **WebhookID** est `4174216298`
2. **WebhookToken** est `JHMHI8qBe7bk2ZwO5U711o3dV_js`

### Mentionner des rôles, tags et utilisateurs

Les mentions s'écrivent de la même façon que dans Discord :

- **utilisateur** : `<@123>`
- **rôle** : `<@&456>`
- **tag** : `@everyone` ou `@here`

Leur effet dépend de la façon dont le message est envoyé :

- **Messages normaux** (par défaut) : votre message est envoyé tel quel, donc toute mention que vous y écrivez notifie normalement.
- **Embeds** (`format=markdown`, ou lorsque `url=` ou `thread=` est défini) : le texte d'un embed ne peut pas notifier, donc Apprise recopie les mentions trouvées dans votre message sur une ligne `👉` qui, elle, notifie.
- **`ping=`** : notifie toujours les mentions que vous indiquez, dans les deux modes, au moyen de cette même ligne `👉`. Séparez-les par une virgule et, dans l'URL, écrivez le `&` d'un rôle sous la forme `%26`, par exemple `ping=<@123>,<@%26456>,@here`.

## Syntaxe

La syntaxe valide est la suivante :

- `https://discordapp.com/api/webhooks/{WebhookID}/{WebhookToken}`
- `discord://{WebhookID}/{WebhookToken}/`
- `discord://{botname}@{WebhookID}/{WebhookToken}/`

Discord prend également en charge différents arguments web. Les valeurs ci-dessous correspondent aux valeurs par défaut et n'ont donc pas besoin d'être précisées, sauf si vous souhaitez les remplacer :

- `discord://{WebhookID}/{WebhookToken}/?tts=No&avatar=Yes&footer=No&image=Yes&batch=Yes`

## Détail des Paramètres

| Variable     | Obligatoire | Description                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------ | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| WebhookID    | Oui         | Première partie des 2 jetons qui vous sont fournis après la création d'un `incoming-webhook`.                                                                                                                                                                                                                                                                                                                     |
| WebhookToken | Oui         | Seconde partie des 2 jetons qui vous sont fournis après la création d'un `incoming-webhook`.                                                                                                                                                                                                                                                                                                                      |
| botname      | Non         | Nom du robot qui doit publier le message. Si aucune valeur n'est fournie, la valeur par défaut consiste à utiliser simplement votre compte, associé à l'`incoming-webhook`.                                                                                                                                                                                                                                       |
| tts          | Non         | Active le Text-To-Speech. La valeur par défaut est **No**.                                                                                                                                                                                                                                                                                                                                                        |
| footer       | Non         | Inclut un pied de message. La valeur par défaut est **No**.                                                                                                                                                                                                                                                                                                                                                       |
| image        | Non         | Inclut une image dans le message afin de représenter le type de notification. La valeur par défaut est **Yes**.                                                                                                                                                                                                                                                                                                   |
| avatar       | Non         | Remplace l'icône d'avatar Discord par défaut par une icône identifiant le type de notification. La valeur par défaut est **Yes**.                                                                                                                                                                                                                                                                                 |
| avatar_url   | Non         | Remplace l'URL de l'icône d'avatar Discord par défaut. Si elle n'est pas définie, Apprise choisit dynamiquement l'URL en fonction du type de message (info, success, warning ou error).                                                                                                                                                                                                                           |
| format       | Non         | Discord envoie du texte brut par défaut. Définissez cette valeur sur `markdown` lorsque vous voulez qu'Apprise utilise les embeds Discord pour une mise en page plus riche.                                                                                                                                                                                                                                       |
| href         | Non         | Définit une URL vers laquelle le titre doit pointer lors de la publication de la notification Discord. Cela force le message au format `markdown` afin de tirer parti de la section `embeds` de Discord. Vous pouvez aussi utiliser `url=` comme alias.                                                                                                                                                           |
| thread       | Non         | Permet facultativement de définir le `thread_id` auquel appliquer votre message.                                                                                                                                                                                                                                                                                                                                  |
| ping         | Non         | Mentions à notifier avec chaque message, comme un utilisateur, un rôle, `@everyone` ou `@here`. Consultez [Mentionner des rôles, tags et utilisateurs](#mentionner-des-rôles-tags-et-utilisateurs) pour le format.                                                                                                                                                                                                |
| batch        | Non         | Lorsque défini sur **Yes** (valeur par défaut), plusieurs pièces jointes sont regroupées en un seul message Discord dans la limite du nombre de pièces jointes par message et de la taille totale autorisés. Définir sur **No** pour envoyer une pièce jointe par message, ce qui correspondait au seul comportement pris en charge avant l'ajout de cette fonctionnalité.                                        |
| template     | Non         | Fournit le chemin vers un fichier JSON à utiliser à la place du payload Discord construit par défaut par Apprise. Utilisez des doubles accolades `\{\{jeton\}\}` pour indiquer les valeurs à substituer avant l'envoi (par exemple `\{\{app_body\}\}` ou `\{\{app_title\}\}`). Le fichier doit produire un objet JSON de webhook Discord valide avec un champ `content` non vide ou un tableau `embeds` non vide. |

## Modèles

L'argument `?template=` permet de fournir un fichier JSON de webhook Discord préconstruit. Apprise lit le fichier, substitue les espaces réservés `\{\{jeton\}\}`, valide le résultat, puis l'envoie -- vous donnant un contrôle total sur la structure du payload sans modifier le code d'Apprise.

Le fichier doit être un objet JSON valide contenant au moins l'un des éléments suivants :

- un champ `content` non vide (message en texte brut), ou
- un tableau `embeds` non vide (chaque entrée doit être un objet JSON)

:::caution
Le fichier de gabarit est lu et validé à chaque envoi. Les fichiers qui ne sont pas du JSON valide, ou qui ne contiennent ni champ `content` non vide ni tableau `embeds` non vide, feront échouer la notification immédiatement. Cela inclut toute tentative de pointer `template=` vers un fichier non-JSON comme `/etc/passwd`.
:::

### Jetons intégrés

Les jetons suivants sont toujours disponibles dans votre gabarit et ne peuvent pas être remplacés :

| Jeton           | Description                                                                                                                              |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `app_id`        | L'identifiant de l'application ; par défaut `Apprise`.                                                                                   |
| `app_desc`      | La description de l'application ; par défaut `Apprise Notification`.                                                                     |
| `app_color`     | La couleur sous forme de chaîne hexadécimale (par ex. `#3AA3E3` pour info). Utile dans les valeurs de chaîne JSON.                       |
| `app_color_hex` | Alias explicite de `app_color` ; même chaîne hexadécimale. À utiliser lorsque vous souhaitez nommer clairement la variante hexadécimale. |
| `app_color_int` | La couleur sous forme d'entier décimal brut (par ex. `3842019`). À utiliser dans le champ `"color"` des embeds Discord.                  |
| `app_type`      | Le type de message : `info`, `warning`, `success` ou `failure`.                                                                          |
| `app_title`     | Le titre de la notification transmis via `--title` / `-t`.                                                                               |
| `app_body`      | Le corps de la notification transmis via `--body` / `-b`.                                                                                |
| `app_image_url` | L'URL de l'image associée au type de message, si elle existe.                                                                            |
| `app_url`       | L'URL de l'instance Apprise (par défaut `https://github.com/caronc/apprise`).                                                            |

### Jetons personnalisés

Tout jeton que vous inventez au-delà de l'ensemble intégré peut être fourni lors de l'envoi via la syntaxe `:cle=valeur` dans l'URL Apprise :

```text
discord://{WebhookID}/{WebhookToken}/?template=/chemin/gabarit.json&:service=api-gw&:env=prod
```

Dans le gabarit, référencez-le sous la forme `{{service}}` ou `{{env}}`.

:::tip
Toutes les valeurs substituées sont échappées automatiquement en JSON. Les guillemets, barres obliques inverses, sauts de ligne et autres caractères spéciaux présents dans votre titre ou corps sont gérés en toute sécurité, sans échappement manuel.
:::

### Gabarits prêts à l'emploi

Choisissez l'un des gabarits ci-dessous, enregistrez-le sous forme de fichier `.json`, et pointez `?template=` vers ce fichier.

<Tabs>

<TabItem label="Texte brut">

Publie un message en texte brut via le champ `content` de Discord. Le gabarit le plus simple -- pas d'embed, pas de couleur.

```json
{
  "content": "{{app_title}}: {{app_body}}"
}
```

</TabItem>

<TabItem label="Embed simple">

Un embed minimal avec un titre et une description. La couleur reflète le type de notification Apprise.

```json
{
  "embeds": [
    {
      "title": "{{app_title}}",
      "description": "{{app_body}}",
      "color": {{app_color_int}}
    }
  ]
}
```

</TabItem>

<TabItem label="Embed enrichi">

Un embed stylisé avec une barre colorée à gauche, un crédit en pied de message et l'image de statut Apprise en miniature.

```json
{
  "embeds": [
    {
      "title": "{{app_title}}",
      "description": "{{app_body}}",
      "color": {{app_color_int}},
      "thumbnail": {
        "url": "{{app_image_url}}"
      },
      "footer": {
        "text": "Envoyé via {{app_id}}"
      }
    }
  ]
}
```

</TabItem>

<TabItem label="Champs CI/CD">

Un embed avec champs en ligne pour les détails de déploiement. Renseignez `{{service}}`, `{{environnement}}` et `{{version}}` via des jetons `:cle=valeur` dans votre URL Apprise.

```json
{
  "embeds": [
    {
      "title": "{{app_title}}",
      "description": "{{app_body}}",
      "color": {{app_color_int}},
      "fields": [
        { "name": "Service",       "value": "{{service}}",       "inline": true },
        { "name": "Environnement", "value": "{{environnement}}", "inline": true },
        { "name": "Version",       "value": "{{version}}",       "inline": true }
      ],
      "footer": {
        "text": "{{app_type}} | {{app_id}}"
      }
    }
  ]
}
```

Exemple d'URL utilisant ce gabarit :

```text
discord://{WebhookID}/{WebhookToken}/?template=/etc/apprise/deploy.json&:service=api-gateway&:environnement=production&:version=v2.3.1
```

</TabItem>

</Tabs>

## Exemples

Envoyer une notification Discord simple :

```bash
# Supposons que notre {WebhookID} soit 4174216298
# Supposons que notre {WebhookToken} soit JHMHI8qBe7bk2ZwO5U711o3dV_js
apprise -vv -t "Titre du Message de Test" -b "Corps du Message de Test" \
   "discord://4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js"
```

Pour utiliser votre propre URL d'avatar déjà hébergée sur un autre site :

```bash
# Supposons que notre {WebhookID} soit 4174216298
# Supposons que notre {WebhookToken} soit JHMHI8qBe7bk2ZwO5U711o3dV_js
# Supposons que notre {AvatarURL} soit https://i.imgur.com/FsEpmwg.jpeg
apprise -vv -t "Titre du Message de Test" -b "Corps du Message de Test" \
   "discord://4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js?avatar_url=https://i.imgur.com/FsEpmwg.jpeg"
```

Envoyer une notification qui mentionne `@everyone` dans le salon :

```bash
# Supposons que notre {WebhookID} soit 4174216298
# Supposons que notre {WebhookToken} soit JHMHI8qBe7bk2ZwO5U711o3dV_js
apprise -vv -t "Bonjour à tous" -b "Message de test qui mentionne @everyone" \
   "discord://4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js"
```

Toujours notifier `@here`, sans l'écrire dans le message :

```bash
# Supposons que notre {WebhookID} soit 4174216298
# Supposons que notre {WebhookToken} soit JHMHI8qBe7bk2ZwO5U711o3dV_js
apprise -vv -t "Attention" -b "Déploiement terminé" \
   "discord://4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js?ping=@here"
```

Envoyer plusieurs pièces jointes dans un seul message Discord (comportement par défaut) :

```bash
# Supposons que notre {WebhookID} soit 4174216298
# Supposons que notre {WebhookToken} soit JHMHI8qBe7bk2ZwO5U711o3dV_js
apprise -vv -t "Titre du Test" -b "Corps du Test" \
   --attach /chemin/vers/fichier1.png \
   --attach /chemin/vers/fichier2.png \
   --attach /chemin/vers/fichier3.png \
   "discord://4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js"
```

Envoyer plusieurs pièces jointes une par message (comportement précédent) :

```bash
# Supposons que notre {WebhookID} soit 4174216298
# Supposons que notre {WebhookToken} soit JHMHI8qBe7bk2ZwO5U711o3dV_js
apprise -vv -t "Titre du Test" -b "Corps du Test" \
   --attach /chemin/vers/fichier1.png \
   --attach /chemin/vers/fichier2.png \
   "discord://4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js?batch=no"
```

Envoyer une notification exploitant la prise en charge intégrée de `markdown` par Discord :

```bash
# Supposons que notre {WebhookID} soit 4174216298
# Supposons que notre {WebhookToken} soit JHMHI8qBe7bk2ZwO5U711o3dV_js
cat << _EOF | apprise -vv "discord://4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js?format=markdown"
# Title

- Bullet 1
- Bullet 2
- Bullet 3
_EOF
```

Envoyer une notification via un gabarit personnalisé (voir l'onglet **Champs CI/CD** ci-dessus) :

```bash
# Supposons que notre {WebhookID} soit 4174216298
# Supposons que notre {WebhookToken} soit JHMHI8qBe7bk2ZwO5U711o3dV_js
# Supposons que le gabarit CI/CD soit enregistré sous /etc/apprise/deploy.json
apprise -vv -t "Déploiement terminé" -b "Tous les contrôles sont passés." \
   "discord://4174216298/JHMHI8qBe7bk2ZwO5U711o3dV_js?template=/etc/apprise/deploy.json&:service=api-gateway&:environnement=production&:version=v2.3.1"
```
