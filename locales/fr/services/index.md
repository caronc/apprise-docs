## Reference

La colonne Fonctionnalites met en avant quelques informations utiles en un coup d'oeil pour comparer les URL de service de cette page.

| Feature Icon | Switch            | Description                                                                                                             |
| ------------ | ----------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 📎           | `has_attachments` | Le service de notification prend en charge les pieces jointes                                                           |
| 📱           | `has_sms`         | Propose un service de notification axe sur les messages SMS/MMS                                                         |
| 🏠           | `has_selfhosted`  | Propose un service de notification compatible avec une solution **auto-hebergee**                                       |
| 🖼️           | `has_image`       | Le service de notification prend en charge l'envoi de l'etat du message sous forme d'images, pour un rendu plus visuel. |

Les protocoles definis sont egalement accompagnes d'une icone indiquant rapidement s'ils utilisent ou non le chiffrement SSL/TLS :

| Protocol Icon | Encrypted/Secure |
| ------------- | ---------------- |
| 🔒            | Oui              |
| 🔓            | Non              |

Pour consulter la liste des services qui ne sont plus pris en charge et savoir pourquoi, visitez le [cimetiere des services](./graveyard/).
:::
