Les guides proposent une **documentation pratique, orientee scenarios**, pour utiliser Apprise dans des systemes reels.

Si vous cherchez des references, des API ou la syntaxe de configuration, consultez plutot les sections [Bibliotheque](../library/), [CLI](../cli/) ou [API](../api/).

## Guides

- **[Utiliser Apprise avec Home Assistant](./hassio/)** : apprenez a integrer Apprise avec Home Assistant afin de diffuser des notifications sur plusieurs services a l'aide d'une configuration unique et coherente.

- **[Utiliser Apprise avec Fail2Ban](./fail2ban/)** : faites evoluer votre instance Fail2Ban pour envoyer des notifications vers un ou plusieurs des <!-- SERVICES:COUNT --> services pris en charge par Apprise.
