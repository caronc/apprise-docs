# API Reference

Complete reference documentation for Apprise APIs and configuration options.

## Python API

Documentation for using Apprise as a Python library.

### Core Classes

- `Apprise`: Main notification manager
- `AppriseConfig`: Configuration file manager
- `AppriseAsset`: Asset and branding customization
- `AppriseAttachment`: File attachment handling

### Methods

Detailed API documentation is being migrated from the [Apprise Wiki](https://github.com/caronc/apprise/wiki).

## CLI Reference

Command-line interface documentation.

### Basic Commands

```bash
apprise [OPTIONS] [SERVICE_URLS]
```

### Options

- `-t, --title`: Notification title
- `-b, --body`: Notification body
- `-c, --config`: Configuration file path
- `-n, --dry-run`: Test without sending
- `-v, --verbose`: Verbose output
